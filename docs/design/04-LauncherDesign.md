# 管理端界面与功能设计

`launcher` 是操作者准备、控制和查看实验的入口。界面采用同一套 Web 页面，在实验主机的 pywebview 窗口或局域网浏览器中使用。操作者可以在主机旁用平板控制实验。被试使用 `simulator` 的驾驶画面与独立 HUD 页面。

## 界面形式

桌面采用 pywebview 无边框窗口，自绘标题栏与窗口按钮。网页与桌面共用标题栏，显示侧栏开关、DRISCA、当前页面、实验预设和连接地址入口，桌面模式额外显示原生窗口操作按钮。页面内容、侧栏和对话框使用统一的圆角样式，原生窗口的圆角随桌面集成实现。

交互原型使用 Basecoat 与 Alpine.js，以静态 HTML 展示页面、表单和交互，固定采用桌面窗口样式。标题栏高度约 38px。正式浏览器入口沿用页面布局并隐藏窗口操作按钮。正式前端使用 Vite、React、TypeScript、Tailwind CSS 和 shadcn/ui，由 Bun 管理依赖，构建产物由 Python 服务提供。

应用占满视口，标题栏和侧栏保持固定，各页面内容在内部滚动。控制台页优先同屏呈现实验所需的操作与状态，日志在独立区域内滚动。侧栏支持收起，主机配置和输入配置集中在导航底部，CARLA 连接与驾驶端状态集中在左下角。标题栏的连接入口弹出操作者控制台与被试 HUD 的地址和二维码，并显示两类页面及合计在线客户端数量。每个打开的页面计为一个客户端。

## 页面划分

| 顺序 | 页面 | 主要用途 |
| --- | --- | --- |
| 1 | 控制台 | 实验启停、状态监控、实验动作、打点与日志 |
| 2 | 方案配置 | 场景与车辆、相机安装、指令与打点 |
| 3 | 数据管理 | 实验记录、日期筛选、勾选导出与录像回放 |
| 4 | 主机配置 | 连接与服务、驾驶显示与画面布局、数据存储 |
| 5 | 输入配置 | 键盘与方向盘 |

## 控制台

控制台页左上方常驻驾驶状态面板，右侧放置事件标记，下方保留快捷指令与日志。状态面板提供被试编号输入，空闲时可编辑，启动、运行和结束期间锁定。车速、模式和控制量始终位于同一位置，空闲时显示待启动状态。主按钮保持固定位置，负责开始与结束实验。保存数据和录像选项位于标题栏的实验预设对话框。点击结束实验立即启动停机流程，同时提供可选备注对话框。操作者可以保存备注或直接跳过，备注独立写入会话记录。

管理端启动时尝试连接 CARLA 一次。侧栏以文字按钮显示“CARLA 服务器已连接”或未连接状态，点击打开连接对话框，填写服务器地址与端口后连接。地址保存到主机配置，实验运行期间锁定连接编辑。检查连接先提交当前主机配置。连接过程中状态点显示脉冲动画，连接按钮和开始实验保持禁用。侧栏收起时保留状态点按钮，悬停显示连接状态与地址。驾驶端的启动与运行状态单独显示。未连接时，开始实验和开始回放按钮禁用，悬停提示先连接 CARLA。回放在实验运行期间同样禁用。

状态区显示车速、限速、挡位、驾驶模式、接管请求和驾驶端运行情况。油门、刹车、转向各展示一组实际车辆控制值。研究数据继续分别记录驾驶人输入与实际控制。

驾驶状态卡片右上角提供实时天气图标按钮。实验运行时打开天气对话框，修改经 300ms 防抖发送到模拟器并立即应用。天气字段来自原生环境目录，切换预设时同步显示完整参数；百分比字段以 0–100 展示，保存为 0–1 强度。雾强度和高度衰减是控制参数，起始距离不是已校准的能见距离。调整记录为环境事件，实验预设保留原有内容。

侧栏 CARLA 状态按钮打开场景控制对话框，集中提供服务器连接、当前地图、地图切换和实时天气。地图列表来自已连接的服务器，实验空闲时可手动切换。切换后刷新当前地图、出生点、车辆蓝图与天气。场景控制修改 CARLA 当前环境，实验启动时按所选预设设置环境。

手动切换地图与实验启动准备世界时，所有操作者页面显示全局等待对话框，阻止页面交互，后端暂停接受修改请求。加载成功后恢复操作；失败后解除等待，显示错误并记录日志。

快捷指令独占一行，按钮从已知指令库中选择。指令库由 Python 代码声明可执行指令、名称、参数类型、约束与执行方式，应用初始化时读取。预设保存指令标识、参数和按钮名称。停止时，编辑快捷入口进入方案配置的指令与打点标签；运行时，点击按钮执行所选指令。编辑窗口只提供已知指令及其参数。

“请求接管”指令包含接管状态与可选语音参数，一次点击完成请求和播报。切换人工驾驶后解除接管请求。控制命令由模拟器应用后上报事件，管理端统一记录。普通调整失败时展示错误，控制权等关键操作失败时停止实验。

键盘反斜杠是驾驶人主动切回人工驾驶，执行模式切换与事件记录。接管语音由 Launcher 的操作者指令触发，语音播放与后续语音服务均归 Launcher 管理。

事件标记使用独立卡片，按预先定义的名称生成按钮，点击即写入一条打点事件。默认提供进入路段、离开路段、任务完成和异常情况，实验开始由启停流程记录。实验开始前，打点区域显示锁定提示和禁用状态，指令与打点定义由方案配置页维护。

日志和事件日志在控制台页查看。日志显示子进程输出与错误；事件显示帧号、时间、事件名称、来源和详情。关闭保存时显示“调试运行”，实时状态、日志和事件照常更新。

连接入口分别提供操作者控制台和被试 HUD 的局域网地址。HUD 展示车速、限速、挡位、转向和驾驶模式。

## 方案配置

方案配置管理 `configs/presets/*.toml`，支持新建、切换、保存与删除预设。世界设置包含地图、重载地图选项、同步模式、世界推进频率、全局天气和初始局部球雾。地图、车辆和实验预设提供搜索选择；下拉选项显示箭头。天气通过独立对话框选择预设并调整全局参数，连续数值采用滑动条与数字输入联动，百分比字段按 0–100 显示，详细天气项折叠展开。同一对话框列出预设中的固定世界空间球雾区域，可增删并编辑中心、半径和密度；这些区域由 worker 在实验启动前创建。运行期天气对话框只调整全局参数。

车辆设置包含蓝图、角色名、默认限速、道路动态限速与启动自动驾驶选项。当前原生接口接入使用人工驾驶，自研自动驾驶完成后开放启用；初始自动驾驶请求在启动前明确拒绝。出生点保存六个位姿字段并记录所属地图，可以从地图出生点中选择、手动填写，或从运行中的最新遥测拾取当前位置。限速使用滑动条与数字输入联动，界面单位为 km/h，保存时换算为 m/s。

出生点与预设地图绑定。修改预设地图时弹出出生点对话框：目标地图已加载且存在预设出生点则随机预选一个，供操作者确认或改选；目标地图没有预设出生点时要求填写完整六个坐标；目标地图尚未加载时可在对话框内加载目标地图，加载完成后随机预选一次。未确认出生点前不能开始实验，开始按钮禁用并提示原因。对话框中的自定义坐标初始为空，必须填写全部有限数值才能确认；已绑定目标地图的预设打开编辑时保留当前坐标。地图目录刷新不会重新随机。

每次连接 CARLA 时读取可用地图、车辆蓝图与当前地图出生点。车辆选择器只提供服务端实际存在的条目；车型初始为空，由操作者从列表选择。

页面分为场景与车辆、相机安装、指令与标记三个标签。标题栏显示“实验预设：名称”，点击打开预设对话框。选中预设后，方案配置页直接编辑对应内容；对话框底部提供新建和删除按钮，正文提供保存数据与录像选项。运行期间锁定预设选择和保存选项。各标签共享一份编辑草稿，修改后经 600ms 防抖自动保存，标签行右端显示保存状态。切换预设和启动实验前提交当前修改，保存失败时显示具体错误。所有页面复用同一套标签栏布局，底部分隔线贯穿整行，标签在窄屏下横向滚动。数据保存与录像选项属于 RunSettings，随启动请求提交。控制台的编辑快捷入口进入相应标签。

### 相机安装

相机安装单独调整四路相机相对车辆的位置、旋转和 FOV，每项使用滑动条与数字输入联动。位置以车辆包围盒中心为 0%，各方向边界为 ±100%；数字框允许填写车身范围外的位置。配置保存比例坐标，1 对应 100%，由 simulator 使用实际车辆包围盒换算为安装坐标，换算包含包围盒中心与旋转。相机旋转与 FOV 使用角度。

管理端显示百分比与位置示意。运行时可由 simulator 提供当前车辆的包围盒供图形展示；车型尺寸表可按离线编辑需要导出。

顶视图按车身尺寸显示相机位置、朝向与水平视野角；侧视图显示安装高度和俯仰朝向。视图切换放在画布左上角，与画面布局统一。画布撑满卡片顶部与图例之间的区域。拖动相机编号修改位置，顶视图调整前后与左右，侧视图调整前后与高度，再通过滑动条和数字框微调。示意图与参数同步更新。右侧参数卡片提供撤销本页相机调整的操作，恢复进入当前页面时的位置。修改自动保存到当前方案。这些参数属于实验预设；画面布局描述后视镜在驾驶屏幕上的位置和大小。

宽窗口下，相机示意与参数两张卡片保持等高；窄窗口下自动改为上下排列。

实验运行时，操作者将修改应用到模拟器，查看实际驾驶画面的效果。参数应用后由模拟器上报相机调整事件。

调好后可保存到当前预设。运行中的相机状态与本次启动配置分别保留，启动配置和调整事件共同描述实验条件。

### 指令与打点

指令按钮和打点名称随当前实验预设保存。通过已知指令库编辑参数，打点列表支持逐项增删。控制台页读取本次运行采用的指令与打点。

## 数据管理

数据管理使用会话记录和录像回放两个固定标签。

### 会话记录

默认显示最近 30 天的会话，允许修改日期区间，并按被试、会话编号和状态筛选。会话表格在内部滚动，日期、筛选、选择和导出控件保持固定。表头复选框选择当前筛选的全部会话，界面持续显示已选数量。日期或状态筛选变化后，已有选择继续保留，操作者可清空后重新选择当前筛选结果。

总会话数、筛选结果与已选数量统一放在表格内部工具栏。

删除所选会话前弹出确认框，确认后一起删除会话记录、逐帧数据与事件，完成后刷新列表并清空选择。正在运行的会话在结束后删除。

列表显示会话编号、起止时间、时长、地图、车辆、记录帧数和备注。详情先展示中文会话摘要、事件日志和实际备注，完整运行配置通过折叠区查看，空备注保持为空。

点击导出后，后端将选中会话的 `sessions.csv`、`data.csv` 和 `events.csv` 写入实验主机配置的导出目录，通过 `session_id` 关联。每次导出使用独立子目录，界面显示进度和完成路径。浏览器与桌面使用同一流程。

### 录像回放

应用管理的录像按表格分页显示，支持名称搜索。点击行选择录像，选中样式与悬停样式分别显示，回放设置中显示当前录像。操作者可以查看摘要或详细信息，设置回放起点、时长、倍速与跟随车辆，再调用 CARLA 回放。回放由已启动的 CARLA 服务端执行，安排在实验结束后进行。基础版先完成录像选择与回放控制。路网工具随相关需求推进。

## 主机配置

标签栏固定，当前标签的设置内容在下方独立滚动。主机配置管理 `configs/machine.toml`：CARLA 地址与端口、连接超时、驾驶窗口分辨率和显示选项、目标帧率、管理端监听地址与端口、数据库、录像与导出目录、语音与日志选项。导出目录使用 `MachineConfig.export_dir`。

页面分为连接与服务、驾驶显示、数据存储三个标签，共同编辑 `machine.toml`。修改经防抖自动保存，标签行右端显示保存状态，修改应用于下次实验；服务监听地址与端口在管理端重启后生效。

### 驾驶显示与画面布局

画面布局在同一张卡片中呈现画布与参数。分辨率选择位于画布左上角，右上角提供后视镜显隐图标与悬停帮助。操作者拖动后视镜调整位置，拖动缩放手柄修改尺寸，也可直接输入像素值。后视镜使用编号与画面外标签对应，宽屏比例下保持标签清晰。位置和尺寸对应实际驾驶窗口，布局写入 `machine.display.layout`。卡片提供撤销本页布局调整和应用操作，修改自动保存到主机配置。驾驶分辨率集中在画布入口选择，支持自定义尺寸。

后视镜初始显隐、屏幕位置和图像尺寸跟随实验主机保存。运行期通过布局命令整体应用，应用后记录事件。主视图采用实际驾驶分辨率。

相机与布局编辑器将草稿和已应用值分别比较，修改后显示“待应用”，生效后更新按钮状态。实验运行期间的布局修改可立即应用，主机配置文件在实验结束后自动提交；驾驶分辨率在实验停止时修改。

## 输入配置

输入配置管理 `configs/control.toml`：方向盘启用、设备编号、按钮编号日志，以及键盘和方向盘的动作绑定。每个动作在每种设备上选择一个按键，界面显示名称，配置保存枚举字符串。按键说明与配置共用名称表。方向盘随动字段保留，功能安排在后续硬件工作中实现。

页面分为键盘和方向盘两个标签，共同编辑 `control.toml`。修改经防抖自动保存，标签行右端显示保存状态，修改用于下次实验。配置组成见[配置管理](../guide/05-Configuration.md)与[配置模型](./08-ConfigurationModels.md)。

配置页和业务画布分别管理自己的编辑状态；相机安装、画面布局各自管理选择和拖拽。共享运行连接与配置自动保存使用独立 hook，页面负责自己的查询与对话框。通用组件直接复用 shadcn/ui，统一的对话框布局、图标操作与页面标签栏由少量组合组件提供。

## 后端与窗口

Python 后端负责实验编排、配置读写、数据访问和模拟器通信，浏览器通过 HTTP 提交操作，通过 SSE 接收状态。桌面与浏览器共用这些接口，通信方案见[管理端前后端通信](./10-LauncherWeb.md)。

子进程使用 Python 标准库 `subprocess` 管理，并加入 Windows Job Object。桌面关闭按钮调用同一套实验停机和管理端退出流程；浏览器关闭标签页只断开该页面连接。具体生命周期见[系统架构](./01-Architecture.md)。

## 交互反馈

卡片辅助操作统一使用 ghost 风格的图标按钮与 tooltip，包括编辑、新建、删除、恢复和清空。开始与结束实验、导出和回放等主要操作保留文字。图标按钮提供无障碍名称，移动端点击直接执行。滚动条使用无箭头的细滑块，滚动或指针靠近轨道时显示，停止操作后自动隐藏。

普通界面文字保持不可选中。输入框、日志、数据表和导出路径等数据区域保留文字选择，便于填写和复制。

标题栏和侧栏共用一种浅灰蓝色，工作区使用另一种浅灰色，卡片保持浅色。侧栏收起与展开使用不同图标，窗口操作使用统一尺寸的 SVG 图标。按钮悬停、侧栏伸缩、对话框打开和状态更新使用短时过渡；动画跟随系统的减少动态效果偏好。通知使用固定水平位置的淡入淡出。操作帮助集中在布局与相机坐标等必要位置，通过即时悬停或键盘焦点浮层查看。对话框遮罩覆盖标题栏下方工作区，标题栏保持清晰；背景业务控件暂停响应，原生窗口管理由桌面壳处理。禁用控件显示灰色状态，打点区域同时提供锁定图标和可用条件提示。

## 组件约定与原型

定稿原型位于 `prototypes/launcher/`。原型采用 Basecoat 标准 Dialog、Button、Tooltip、Switch、Tabs、Command 与 Toast，Alpine.js 管理业务状态。Dialog 使用原生模态元素的标题、正文和页脚结构，正文独立滚动，焦点与 Esc 交由组件处理。

正式前端的通用控件统一使用 shadcn/ui：对话框、选择器、搜索选择、输入框、按钮、复选框、Switch、滑动条、标签页、折叠区和进度条共用组件库实现。保留原型已确认的紧凑布局、配色和操作流程。相机画布、拖拽换算及实验状态切换属于业务交互。组件样式调整集中在主题与必要布局，定位、层级和选中状态沿用组件公开结构和行为。字体使用系统 UI 字体，应用标识复用项目图标。

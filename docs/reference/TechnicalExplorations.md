# 技术探索

本文收录多人联动与服务端定制的方向性方案，供相关需求出现时查阅。当前实施安排见[开发路线图](../design/06-Roadmap.md)。

## 多机分布式多人联动

每台驾驶台运行独立的本地 CARLA 服务端，在本机渲染驾驶画面。一个同步服务广播各主车的位姿状态，其他玩家的车辆在本机世界中以代理对象呈现，位置通过插值或外推更新，碰撞由简化运动学仲裁。

这一方案将跨机传输集中在车辆状态上，已有方案估算为每车约 100 Bytes、30 Hz。实施工作包括状态同步、代理车辆、插值与碰撞仲裁，需要结合多人实验需求单独设计。

## CARLA 服务端插件定制

可在 CARLA UE4 插件的 `PixelReader.h` 接入硬件视频编码或 Windows 共享内存，调整相机像素的传输路径。已有路线分析与测量见[渲染与画面传输参考](./RenderingPipeline.md)。

评估从实验机的实际相机回读瓶颈出发，同时考虑约 200 GB 的 UE4 源码构建空间、私有分支维护与服务端分发工作。

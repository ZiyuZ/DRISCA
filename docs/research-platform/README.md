# 交通行为研究平台方案

本目录记录 DRISCA 面向交通行为研究的新方案，覆盖原生驾驶、专用接口、集中采集、多终端交互和交通模型接入。当前为讨论与开发规划初稿，功能进展以实际代码和运行记录为依据。

总体方向是复用 CARLA 的地图、车辆、物理、动画与渲染能力，建立 DRISCA 自己的 WebSocket 接口和 Python 客户端。驾驶终端执行本车驾驶并生成画面，中心服务组织实验、运行交通模型和保存数据。现有 Web Launcher 继续作为操作者入口。

# 常见问题

本文汇总日常实验准备与运行中常见的问题及处理方法。如按步骤排查后仍未解决，请保存左下角日志详情并联系系统维护人员。

## 启动与连接

### 点击“启动 CARLA”后长时间没有连接成功

1. 检查 **主机配置 → 连接与服务** 中填写的 `CarlaUnreal.exe`（或 `UnrealEditor.exe` 与 `.uproject`）路径是否正确。
2. 首次启动或切换地图后着色器编译可能需要较长时间，可在配置中适当调大启动超时时间。
3. 确认本机没有残留的旧 CARLA 进程占用 `2000` 或 `7910` 端口；如有残留，在任务管理器中结束后重试。

### 管理端窗口无法打开或白屏

1. 确认已安装 **Microsoft Edge WebView2 Runtime**。
2. 在项目目录打开终端执行 `bun run --cwd frontend build` 重新构建界面，再双击 `DRISCA.exe`（或运行 `uv run -m drisca.launcher` 查看具体错误）。

## 场景与实验运行

### 启动实验提示“出生点不在有效道路上”

切换新地图后，原预设中的出生点坐标可能落在道路之外。进入 **场景** 页面，打开主车出生点设置，从当前地图的预设出生点列表重新选择一个位置（或在自由视角中移动至道路上方点击“拾取当前位置”）并保存。

### 三屏显示位置偏移或窗口被裁切

Windows 的显示缩放比例（如 125%、150%）会影响窗口实际像素位置。建议在 Windows 显示设置中检查各屏幕的排列顺序与缩放比例，必要时将驾驶屏缩放设为 100%，再在 **主机配置 → 驾驶显示** 中微调 X/Y 坐标。

### 语音指令没有声音

1. 检查 **主机配置 → 连接与服务** 中是否已开启语音播报（TTS）。
2. 检查 Windows 默认音频输出设备是否正确，以及系统音量是否静音。

## 数据与回放

### 升级版本后提示数据库版本不匹配

当平台升级了数据表结构（Schema 版本变更）时，旧版数据库文件不会自动覆盖，以防止误改历史实验数据。请将旧的 `data/experiments.sqlite3` 备份并移走（或改名），然后重新启动管理端，系统会自动创建新版数据库。

### 录像回放时提示找不到地图

录像文件只记录车辆运动轨迹，回放时仍需要 CARLA 中安装了对应的地图。如果实验是在新加坡等扩展地图上录制的，请确认当前 CARLA 程序已安装对应的地图包（安装方法见[自定义地图与独立地图包](../deploy/03-CustomMaps.md)）。

# 快速开始

DRISCA 在 Windows、Python 3.14 与 CARLA 环境中运行。桌面窗口使用 Edge WebView2，网页和平板通过实验主机的服务地址访问同一套控制台。

左下角的 Unreal 入口按主机配置启动编辑器版或打包版 CARLA。一个管理端可连续开展多次实验，实验结束后保留 Unreal。命令行也能启动程序和控制实验，详见[管理端命令行](./06-LauncherCLI.md)。

## 准备环境

安装 uv、Bun 和 just，准备项目所用的 CARLA 服务端及仓库配置的客户端 wheel。Windows 安装 Edge WebView2 Runtime，方向盘连接与驱动按实验设备准备。

在仓库根目录安装依赖并构建界面：

```bash
uv sync
bun install --cwd frontend --frozen-lockfile
just frontend-build
```

界面构建后由 Python 服务提供，实验运行时使用构建好的资源。

## 准备配置

管理端启动时自动将缺少的机器、控制和基础预设配置从对应示例复制生成，已有配置继续保留。生成文件为 `configs/machine.toml`、`configs/control.toml` 和 `configs/presets/basic.toml`。

启动后按实验环境填写 CARLA 地址、显示器参数、车辆与出生点。方向盘按实际设备启用，输出目录由机器设置维护。完整说明见[配置管理](./05-Configuration.md)。

## 启动与运行

先按[CARLA 服务端](./02-CarlaServer.md)启动场景服务，再打开管理端：

```bash
just launcher
```

左下角显示 CARLA 与驾驶端状态。点击 CARLA 状态按钮，在对话框中填写服务器地址与端口并连接，地址保存到主机配置。在标题栏点击实验预设，选择预设并确认保存数据与录像选项，在控制台填写被试编号后开始实验。结束实验时可填写本次备注。

连接后，同一个场景控制对话框提供当前地图、地图切换与实时天气调整。地图列表来自服务器，实验空闲时可手动切换，加载期间所有控制台显示等待界面。天气调整立即作用于当前场景；实验启动时使用所选预设中的地图与天气。

方案配置页的场景、相机和指令标签共同编辑当前预设，修改自动保存，标签栏右侧显示保存状态。主页的编辑入口跳转到对应标签，运行状态点击指令执行，实验打点直接点击相应名称。相机安装在方案配置中调整，画面布局在主机配置的驾驶显示中调整，分别保存到实验预设和主机配置。

点击结束实验立即停机，可以在弹出的对话框填写备注或跳过。等待驾驶端退出与会话收尾后，再开始下一次实验。实验记录按日期筛选，勾选后导出到设置中的导出目录；录像在实验数据的录像回放标签中选择。

## 浏览器与平板

标题栏的连接图标提供使用实验主机 IPv4 地址的控制台和被试 HUD 链接与二维码。服务默认监听 `0.0.0.0`，端口为 `7900`。平板与实验主机连接同一局域网后，在浏览器打开相应地址。

使用浏览器控制时也可以仅启动服务：

```bash
just launcher --web
```

操作者控制台位于 `/`，被试 HUD 位于 `/hud`。关闭浏览器页面后，实验仍由管理端服务运行。

## 开发入口

调试界面时运行 `just launcher --dev`，同时启动 Python 管理服务和 Vite，桌面窗口加载开发页面。修改 React 与 CSS 后自动热更新。Vite 自动选取空闲的本机端口，接口代理到机器配置中的管理服务端口。关闭窗口时同时回收 Vite。Python 代码修改后重新运行命令。

```bash
just frontend-dev
just launcher --dev
just frontend-check
just frontend-build
just lint
just rumdl
```

前端开发服务代理 Python 管理端接口。Python 与硬件错误在管理端日志中查看，实际 CARLA 与方向盘验证在实验环境完成。
